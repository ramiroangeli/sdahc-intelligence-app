# Publisher runbook

Roles: an Editor writes and saves drafts. Only a Publisher publishes, changes status, approves commercial details and withdraws. Nothing is public until a Publisher publishes it.

## 1. Create a listing
Listings, Add listing, search the CRM by address, choose the property. If it is already on the website, choose to bring it in as a draft. Prepare tab: title, description, address shown (street name only, never a house or unit number), how the price is shown, photographs (at least one; the first is the cover; floorplans go last; describe what is visible).

## 2. Write a long description
One field, plain text. Blank line = new paragraph. Lines starting with `- ` make a bullet list; a line ending in a colon above a list is its label; a short line on its own is a heading. Save often. You can draft anything, including figures. The preview shows the first paragraph with "Read full description" and "Show less", as the website will.

If the text contains dollar amounts, income or yield, the preview shows a warning naming the words and lines and the text cannot be published until they are removed. Put lease, occupancy, income and yield in Investment details instead. Victorian listings cannot publish income or yield at all for now.

## 3. Optional property information
Open Optional details: Property (bathrooms, car spaces, areas), SDA (bedrooms, places, OOA wording), Marketing agency. These publish with the listing. Investment details stay private until approved (section 6).

## 4. Preview, then publish
Preview and check: read the card and page, clear everything under "Before you publish". "Test without publishing" is an optional rehearsal. Publish: "Review and publish". The website builds, tests, opens and merges a change, and checks the live page. This takes several minutes and continues if you close the browser. Progress shows on the Publish tab.

## 5. Update, status, withdraw
- Update: edit the draft, save, Publish tab shows "Changes since live"; publish the update.
- Status (Publisher): Manage tab, Available, Under offer or Sold. Sold hides price and commercial details.
- Withdraw (Publisher): Manage tab, "Withdraw this listing", type the address, give a private reason. It permanently removes the listing from public marketing and cannot be undone in the Listings Manager. Photo files may remain reachable by direct address and search engines may keep copies for a while.

## 6. Approve commercial details (Publisher)
The Editor enters lease and occupancy status (separate), tenure, income and yield (not for Victoria), basis and provider wording. Save first. Then "Review and approve for publication", tick the confirmation, say what was checked and against what, approve. Provider arrangement wording needs its own tick. "Fully occupied" cannot be approved while the CRM shows fewer participants. Editing any value withdraws the approval; putting the old value back does not restore it. "Withdraw approval" makes it private again.

## 7. When something goes wrong
| Message or state | Meaning and action |
|---|---|
| Someone else saved this draft first | Reload; copy your text from the screen first if needed. |
| The Notion record changed | Review the changes and save to accept them. |
| Not ready (reasons listed) | Fix each listed item; the reason says what to change. |
| Publication failed at a named step | Nothing public changed. Read the step, fix the cause (often text or a photo description), publish again. If it repeats, tell an administrator. |
| Job stuck on "waiting" | Wait, then reload. If it stays for more than 30 minutes tell an administrator; do not start a second publication. |
| Merged but not verified | The change is merged and deploying; reload the Publish tab shortly. |
| Wrong status or wrong text live | Fix the draft and publish an update; for status use Manage. Escalate if it is urgent. |
